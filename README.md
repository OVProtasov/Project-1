# F : H (Funny Horoscope & API Service)

Микросервис на базе FastAPI и Uvicorn, который предоставляет системные эндпоинты, а также умеет приветствовать пользователей и генерировать шуточные гороскопы по знаку зодиака.

## Подготовка

Создайте и активируйте виртуальное окружение, затем установите зависимости:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

## Настройки окружения

Настройки приложения (название, автор, версия) берутся автоматически из файла .env. Убедитесь, что он создан в корневой директории проекта.

## Запуск приложения

Запустите сервер с помощью Uvicorn (обратите внимание, что файл приложения называется app_final.py):

python3 -m uvicorn app_final:app --reload --host 127.0.0.1 --port 8000

После успешного запуска доступны:
- Главная страница: http://127.0.0.1:8000
- Интерактивная документация (Swagger UI): http://127.0.0.1:8000/docs

## Проверка работоспособности (GET-запросы)

Вы можете проверить базовые эндпоинты через терминал с помощью curl:

# Проверка работоспособности сервиса
curl http://127.0.0.1:8000/

# Проверка статуса (health check)
curl http://127.0.0.1:8000/health

# Проверка версии приложения (из .env)
curl http://127.0.0.1:8000/version

# Проверка детальной информации (название и автор)
curl http://127.0.0.1:8000/info

## Проверка POST-запросов (Инпут и логика)

### 1. Приветствие (/hello)
Эндпоинт принимает имя в формате JSON и возвращает персональное приветствие.

curl -X 'POST' \
  'http://127.0.0.1:8000/hello' \
  -H 'Content-Type: application/json' \
  -d '{"name": "Алексей"}'

### 2. Шуточный гороскоп (/horoscope)
Эндпоинт принимает строку в формате Имя Знак (через пробел) и возвращает сгенерированный шуточный прогноз на основе словаря знаков зодиака.

curl -X 'POST' \
  'http://127.0.0.1:8000/horoscope' \
  -H 'Content-Type: application/json' \
  -d '{"text": "Мария дева"}'

## Использование интерактивного клиента (client.py)

Для удобного тестирования из командной строки вы можете использовать скрипт client.py. 

Скрипт устроен умно: 
- Если вы введете одно слово (например, Иван), он автоматически вызовет эндпоинт /hello.
- Если вы введете два или более слов через пробел (например, Иван овен), он передаст данные на эндпоинт /horoscope.

Как запустить клиент:
python3 client.py
